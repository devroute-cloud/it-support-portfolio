## Topics 📚
- pwd (Print Working Directory)
- ls (List)
- cd (Change Directory)


### What I Learned
- 1. The commands (Pwd, Ls, and Cd) are the *ABC* of the network on the Linux Terminal.
- 2. They give access to understand where you are and to know what's there to my around you.
- 3. They are very necessary for can to continuo the next level. 


### Linux Commands and Their Purpose
- pwd = This command has the current directory.
- Ls = This command has the List files.
- cd = This command has the go one level up
