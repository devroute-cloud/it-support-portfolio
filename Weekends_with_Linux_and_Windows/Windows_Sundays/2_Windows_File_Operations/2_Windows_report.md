## Linux Commands and Their Purpose✍

* mkdir = This command create new files and directorys, when you're working.
* copy = The following command, we can use it to copy files to other local.
* move = The “move” command is very useful because it allows us to copy and move files or folders to other local locations on our workstations.
* del = The following command is very useful because delete files and folders, so use it with care.
* New-Item = This command can create a new files, folders or empty folders.
